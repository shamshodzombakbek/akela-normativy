Akela Normativ Sync — Windows
=============================

Что делает программа
--------------------
1. Входит в Битрикс24 (логин/пароль).
2. Открывает «Отчёты о работе» и скачивает Excel Normativ_*.xlsx.
3. Кладёт файлы на Общий диск:
     Akela Normativy / YYYY-MM-DD /
4. Сайт (streamlit) забирает отчёты уже с Диска.

Нужен установленный Google Chrome.

Установка
---------
1. Распакуйте zip.
2. Запустите AkelaNormativSync.exe
3. Заполните один раз:
   - BITRIX webhook URL (право disk)
   - Логин и пароль Битрикс24 (учётная запись, которая видит все отчёты)
   - Google Drive folder ID + JSON-ключ (как на сайте)
4. «Сохранить настройки» — автосинхронизация включится сама.
5. install_windows_autostart.bat — работа в фоне при входе в Windows.

Окно: каждые 10 мин, 16:00–18:30 (Ташкент).
Кнопка «Синхронизировать сейчас» — сразу, в любое время.

Лог: %APPDATA%\AkelaNormativSync\sync.log
