Akela Normativ Sync — Windows
=============================

1. Распакуйте zip в любую папку.
2. Запустите AkelaNormativSync.exe
3. Заполните настройки (один раз):
   - BITRIX webhook URL (право disk)
   - Google Drive folder ID (как на сайте streamlit)
   - JSON-ключ Google (кнопка «Обзор…»)
4. Нажмите «Сохранить настройки» — автосинхронизация включится сама.
5. Для работы без открытия окна: запустите install_windows_autostart.bat
   (программа будет в фоне при каждом входе в Windows).

Синхронизация: каждые 10 мин, в окне 16:00–18:30 (Ташкент).
Берёт Excel с Диска: Akela Normativy / YYYY-MM-DD /

Лог: %APPDATA%\AkelaNormativSync\sync.log
